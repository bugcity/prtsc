# Prtsc

Screenpresso に着想を得た、Windows 用のスクリーンショット・注釈アプリの初期実装です。独自の UI を持ち、画像と編集データをローカルに保存します。

## 起動

Windows x64 と .NET 10 Desktop Runtime が必要です。開発には .NET 10 SDK を使用します。動画録画に [ScreenRecorderLib 7.0.1](https://github.com/sskodje/ScreenRecorderLib) を使用し、NuGet から復元します。録画には Media Foundation と Visual C++ Redistributable x64 が必要です（Windows N / KN では Media Feature Pack を追加してください）。ライセンスは `THIRD_PARTY_NOTICES.md` に同梱しています。

```powershell
dotnet run --project Prtsc.csproj -c Release
```

ビルド済みの場合は `bin\Release\net10.0-windows\Prtsc.exe` を直接起動できます。

## できること

- 範囲撮影、クリックしたウィンドウの撮影、画面全体の撮影。撮影時はアプリ自身を隠します。
- 範囲・ウィンドウ選択中も実際の画面は動き続けます。開始時の静止画は使わず、範囲を確定して選択画面を閉じた直後に撮影します。
- Chrome・Edgeでは、表示中ページにマウスを合わせてページ領域だけをクリック撮影できます。タブバー・アドレスバーを除外し、スクロール先は含みません。拡張機能やブラウザの起動オプション変更は不要です。Altを押している間はウィンドウ全体を選択します。
- `PrtSc` によるグローバル撮影。アプリ起動中に利用できます。ドラッグで範囲を指定するか、クリックでウィンドウを選択します。
- 複数モニターを含むデスクトップの撮影。範囲の座標を画像のピクセル座標に変換します。
- 矢印、四角、丸、自由描画、蛍光ペン、複数行の文字、連番マーカー。
- 既存注釈の選択・移動・色・太さの変更。矢印や図形のサイズ変更、文字と番号の内容の再編集、Undo / Redo。
- 文字サイズを線の太さから独立して指定。フォント・背景色・枠線の色と太さを設定でき、文字の書式・描画色・矢印スタイルを再起動後も保持。
- Ctrl / Shift＋クリックによる注釈の複数選択、一括移動・削除・色変更、複製、最前面／最背面移動、矢印キーでの微調整。
- 撮影中のカーソル位置を拡大鏡で表示し、範囲・ウィンドウのサイズを実ピクセルで表示。
- 撮影ホットキーを変更可能（初期値 PrtSc）。Windows 起動時のトレイ起動を設定でき、二重起動時には既存アプリのギャラリーを開きます。
- 矢印はグラデーション・標準・塗りつぶし・太い矢印・白抜き・両矢印・破線・曲線・丸付きの9スタイル。見本付きの「矢印スタイル」から選択できます。
- 履歴の自動保存・再読み込み・削除。元画像と注釈データを別々に保持します。
- 設定で描画方法を選択可能。既定は省メモリのソフトウェア描画で、ハードウェア優先（WPFの自動判定）にも切り替えられます。変更はアプリ再起動後に反映します。
- サムネイルは必要なときに読み込み、最大420×300px・32枚のキャッシュで保持。ギャラリーと左側ライブラリは表示する行だけを生成し、大量保存時の画像の一括読み込みを避けます。
- PNG の書き出しと、注釈を含む画像のクリップボードコピー。
- PNG / JPEG / BMP / GIF / TIFF の読み込み、ファイルのドロップ、画像の貼り付け。
- 最小化するとタスクトレイに常駐。アイコンの左クリックでギャラリーを開き、過去の画像をコピー・編集できます。
- 撮影成功時は自動で画像をクリップボードにコピー。メインモニターの右下にプレビューを表示し、設定した秒数（既定3秒）で薄くなって閉じます。設定の「撮影後の通知」で0〜60秒を指定でき、0秒なら通知を表示しません。変更は次の撮影から反映し、再起動後も保持します。通知を無効にしても保存と自動コピーは行います。消える前にクリックすると、その画像の編集画面を開きます。
- 実行ファイル・ウィンドウ・タスクトレイに専用アイコンを設定。
- 保存枚数の上限（1〜100,000枚）または無制限を設定。上限を超えた画像を古い順に削除します。
- ギャラリーと編集画面左側のサムネイルから、注釈を含む原寸の PNG を他アプリへドラッグできます。
- 編集中だけの表示ズーム（1〜800%、全体表示・100%表示・スクロール）と、注釈を編集可能なまま保持するトリム。
- ツールバーは要素を縮小せず基本2段に配置し、画像エリアを拡大。狭いウィンドウでは折り返します。
- 範囲・ウィンドウ選択・画面全体のMP4録画（H.264・30fps）、一時停止・再開・停止・破棄。
- 録画開始時に「PC の音」「マイク」を個別に選択。初期値は両方オフ。カーソルと赤い円の合成は初期値オン。
- 移動中の赤い円は直径24px、ボタン押下・ドラッグ中は48pxへ滑らかに拡大。離すと24pxへ戻り、動画にも合成します。
- 録画した動画のギャラリー表示・再生・シーク・MP4保存・ファイルとしてコピー／DnD。

GIF / TIFF は先頭フレームの静止画として読み込みます。撮影開始前に編集画面を表示していた場合は、撮影後にその編集画面を復元します。編集中の画像や表示倍率は、保存枚数の上限によってその画像が削除されない限り維持します。トレイから撮影した場合は編集画面を自動表示せず、プレビューのクリックかギャラリーの「編集」から開きます。撮影をキャンセルした場合は、それまで表示していた画面に戻ります。

## 操作

範囲選択は透明な画面で行うため、背後の動画やアニメーションは停止して見えません。保存するのは選択開始時の画像ではなく、クリックやドラッグで確定した直後の表示です。選択用の枠・案内・拡大鏡が消えてから撮影します。選択操作中のクリックはPrtscが受け取り、背後のアプリには渡しません。

拡大鏡はカーソル周辺の最大25×25pxだけを約80ms間隔で更新し、選択終了時に停止・解放します。Windows側で選択画面をキャプチャから除外できない環境では、拡大鏡の画像を非表示にして座標・選択寸法のみ表示します。

撮影選択画面では、ブラウザのページ内にマウスを合わせると「ページ領域」の枠を表示し、ブラウザのツールバー付近ではウィンドウ全体の枠を表示します。Altを押すと、ページ内でもウィンドウ全体を選択できます。ドラッグによる任意範囲の撮影は従来どおりです。ページ領域の検出にはWindows UI Automationを使い、初回の初期化待ちを再試行します。検出は最大約1.2秒で打ち切り、取得できないブラウザではウィンドウ選択を使用します。ウィンドウが検出中に移動・リサイズされた場合もウィンドウ選択へ戻します。録画範囲の選択にも同じ操作を利用できますが、録画開始後のページ移動やウィンドウ移動は追尾しません。

Undo / Redo の履歴は、その画像を編集対象にしている間は件数制限なく保持します。トレイに隠しても維持し、別の画像へ切り替えたときや対象を削除したときに解放します。ライブラリが空になったときや動画へ切り替えたときは、編集キャンバスに残った元画像の参照も解放します。

### 動画録画

編集画面の「● 動画を録画」、ギャラリーの「● 録画」、またはトレイの右クリックメニューから開始します。開始前に録画範囲・PC の音・マイク・マウス操作の表示を選びます。音声を選んだ場合は Windows の既定の再生／録音デバイスを使用し、両方を選ぶとミックスします。チェックしたデバイスが使えない場合はエラーを表示します。

「範囲／ウィンドウを選択」ではドラッグで範囲を指定し、クリックでウィンドウの表示領域を選べます。**ウィンドウは選択時の画面位置と範囲を固定して録画**するため、移動したウィンドウを追尾する方式ではありません。「画面全体」は複数モニターを含みます。H.264 の制約に合わせ、幅・高さが奇数の場合は右端／下端を1pxだけ除いて偶数にします。

録画中は専用パネルに経過時間と「一時停止／再開」「停止して保存」「破棄」を表示します。パネル自体は録画から除外します。トレイの「録画を停止して保存」からも終了できます。アプリの「終了」を選んだ場合は、録画の保存を終えてから終了します。録画中の静止画撮影は抑止します。

赤い円は35%程度の不透明度で動画に直接合成します。直径24pxから48pxへの拡大・縮小は約150msです。左・右・中央・サイドボタンのいずれかを押している間は拡大状態を維持し、ドラッグにも追従します。録画範囲の外では表示しません。マウス表示をオフにすると、カーソル本体と赤い円の両方を記録しません。

録画後は元の編集画面／ギャラリーに戻り、既存の編集対象を維持します。トレイから開始した場合は保存後にギャラリーを開きます。動画は「再生」から専用プレイヤーを開き、再生・一時停止・シークができます。動画の「コピー」は画像ではなく MP4 ファイルのコピーで、DnD も MP4 の独立したスナップショットを渡します。

動画も保存上限の1件として数えます。上限による削除・手動削除では動画本体とプレビューを削除し、再生中なら先にプレイヤーを閉じます。動画トリム・字幕・録画後のマウス表示の再編集はこの版には含みません。

### 静止画と注釈

1. `PrtSc` または「範囲をキャプチャ」で選択画面を開きます。ドラッグで範囲を指定し、クリックで枠の付いたウィンドウを撮影します。「ウィンドウを選択して撮影」ボタンではクリック専用モードで開始します。`Tab` でモードを切り替え、`Esc` で中止できます。
2. 撮影した画像は自動コピーされます。右下のプレビューをクリックすると編集画面が開きます。プレビューが消えた後も、トレイアイコンの左クリックでギャラリーから開けます。
3. 上のツールバーで注釈を選び、画像の上でドラッグします。文字と番号はクリックして配置します。
4. 「選択」または `V` で既存の注釈をクリックし、ドラッグで移動できます。矢印・四角・丸・蛍光ペン・ペン線は端の丸をドラッグすると大きさを変更できます。ペン線は反対側の端を固定して描いた形を保ちながら伸縮・回転します。閉じた線も端点を動かせます。文字と番号はダブルクリックまたは「文字を編集」で内容を変更します。
5. 選択した注釈は色・太さの変更や「注釈を削除」も可能です。「画像を削除」はキャプチャ全体を履歴から削除します。
6. 「コピー」または「PNG を保存」で編集結果を取り出します。ギャラリーの「コピー」も、保存済みの注釈を含む画像をコピーします。

| キー | 操作 |
| --- | --- |
| PrtSc | 撮影の選択画面（ドラッグで範囲、クリックでウィンドウ） |
| Tab | 撮影の選択画面で範囲 / ウィンドウ専用モードを切替 |
| Ctrl+O / Ctrl+V | 画像を開く / 画像を貼り付け |
| Ctrl+S / Ctrl+C | PNG 保存 / 画像をコピー |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl / Shift＋クリック | 選択ツールで注釈の追加選択／選択解除 |
| Ctrl+A / Ctrl+D | すべての注釈を選択 / 選択した注釈を複製 |
| Ctrl+Home / Ctrl+End | 選択した注釈を最前面 / 最背面へ移動 |
| Ctrl+PageUp / Ctrl+PageDown | 選択した注釈を1つ前面 / 背面へ移動 |
| 矢印キー / Shift+矢印キー | 選択した注釈を1px / 10px移動 |
| Ctrl+ホイール / Ctrl++ / Ctrl+- | 表示だけを拡大・縮小 |
| Ctrl+0 / Ctrl+1 | 画像全体 / 100%表示 |
| C / Enter | トリムツール / 選択範囲を適用 |
| V / Delete | 注釈を選択 / 選択した注釈を削除 |
| A / R / E | 矢印 / 四角 / 丸 |
| P / H / T / N | ペン / 蛍光ペン / 文字 / 番号 |
| Esc | 撮影・描画・移動を中止、選択を解除 |

色と太さは、注釈が選択されていれば選択中の注釈に、選択されていなければ次に追加する注釈に適用されます。文字のサイズは線の太さから独立しており、太さのスライダーで文字サイズは変わりません。矢印スタイルの変更は、複数選択中でも矢印だけに適用します。

テキストの追加・編集ダイアログ、または「編集操作 ▾ → 文字の書式…」から文字サイズ（pt・代表的なサイズをコンボボックスから選択、任意入力も可能）、フォント、背景色、枠線の色と太さを設定できます。色は名前や `#RRGGBB`、透明度付きの `#AARRGGBB` で指定し、`Transparent` で背景や枠線を非表示にできます。追加・編集ダイアログでは、入力した文字をプレビューしながら書式を設定できます。確定すると文字と書式をまとめて適用し、変更した書式を次回の初期設定にも保存します。キャンセルした場合は画像と初期設定を変更しません。「文字の書式…」では選択中の文字と、次に追加する文字の初期設定に反映します。既存画像の文字は、書式を変更するまで従来の見た目を保持します。文字サイズは 12pt＝16px、18pt＝24px（96dpi）で描画し、既存の文字サイズはそのまま保持します。書式情報は注釈とともに保存し、コピー・PNG保存・DnD では画像に合成します。

複数選択は「選択」ツールで Ctrl または Shift を押しながら注釈をクリックします。Ctrl+A ですべての注釈を選べます。選択済みの注釈をドラッグするとまとめて移動します。複製・重なり順は「編集操作 ▾」からも操作できます。複製は元の位置から12pxずらして配置し、グループ内の重なり順を維持します。複数注釈の操作も1回の Undo / Redo で取り消し・再適用できます。

太さのスライダーを手動で変更すると設定を保存し、`Prtsc.exe` を再起動しても同じ太さを使います。既存の注釈を選択したときはその注釈の太さを表示しますが、選択だけでは保存した描画用の太さを上書きしません。描画ツールへ戻ると保存した太さに戻ります。既存注釈の太さを手動で変更した場合は、以後の描画用の太さにも反映します。

### ズームとトリム

画面右下の「−」「＋」または `Ctrl+マウスホイール` で表示倍率を変更できます。「100%」は原寸表示、「全体」は編集領域に収まる倍率に戻します。拡大時はスクロールバーで画像内を移動できます。倍率は編集時だけの表示設定で、保存・コピー・DnD の画像サイズや画素には影響しません。別の画像を開くと全体表示になります。

「トリム」または `C` を選び、画像上で残す範囲をドラッグして「適用」または Enter を押します。キャンセルまたは Esc で取り消せます。確定後も注釈は位置・形・文字内容を編集でき、Ctrl+Z / Ctrl+Y でトリム自体を元に戻す・やり直すこともできます。範囲はライブラリに保存し、再起動後も反映します。

トリムは元画像を上書きせず、切り出し範囲を保存する方式です。トリム範囲外の注釈もデータとして保持しますが、コピー・PNG保存・DnD には切り出した範囲だけを画像として出力します。トリムで文字の折り返しや矢印の形は変えません。Undo / Redo の操作履歴は現在開いている画像の編集セッション内で有効です。

### 保存枚数とドラッグ共有

編集画面左下の「ライブラリの設定」、またはギャラリーの「設定」から保存枚数を変更します。初期値は無制限です。上限を下げると適用時に超過分を削除し、以後の撮影・画像読み込み・起動時にも上限を適用します。削除予定の枚数は設定画面に表示します。削除対象は古い画像の元データ・注釈・プレビューすべてで、復元できません。コピーや書き出しで取り出したファイルには影響しません。

ギャラリーか編集画面左側の**画像部分**を押してドラッグすると、PNG ファイルとしてエクスプローラーやファイルのドロップを受け付けるアプリに渡せます。クリックだけなら従来の選択・編集操作になります。出力はサムネイルではなく原寸の画像に注釈を合成したものです。ライブラリ側の編集データを移動・削除せず、コピーとして渡します。

ライブラリに画像がある間は、アプリを再起動しても注釈を再編集できます。コピーや PNG 保存は元画像と注釈を合成した画像を出力し、ライブラリ内の元画像・注釈データは保持します。選択枠や編集ハンドルは出力しません。Undo / Redo は現在開いている画像の編集操作に適用されます。

矢印ツールでスタイルを選ぶと、次に描く矢印に適用します。設定がない場合の初期スタイルは「グラデーション」で、以後は手動で選んだスタイルを再起動後も使用します。細い尾が矢じりに向かって太くなる形で、始点の不透明度20%から終点付近の100%へ変化します。左向き・上向き・斜めでも、描いた始点から終点に沿ってグラデーションが付きます。

既存の矢印を選択してから変更すれば、その矢印のスタイルを変更できます。色・太さ・端点の編集と Undo / Redo にも対応し、ライブラリの保存データにスタイルを保持します。以前のバージョンでスタイル情報なしで保存した矢印は「標準」として読み込みます。曲線は端点に応じて自動で曲がる形です。[Screenpresso の公式マニュアル](https://www.screenpresso.com/docs/screenpressohelp.pdf) の矢印ツールを参考にした独自のスタイルです。

ウィンドウ撮影は、選択画面を開いた時点で画面に表示されている画像を、対象ウィンドウの枠で切り出します。画面外の部分は除外し、他のウィンドウに隠れている部分は画面に見えている状態で写ります。最小化したウィンドウ、別の仮想デスクトップの非表示ウィンドウ、デスクトップ背景とタスクバーは選択対象にしません。

### PrtSc が反応しない場合

撮影ホットキーは「ライブラリの設定」で変更できます。キー入力欄をクリックして組み合わせを押し、「保存して適用」で即時反映します。「PrtSc に戻す」で初期値へ戻せます。単独キーは PrtSc / F1〜F24、それ以外は Ctrl・Alt・Shift と組み合わせます。登録に失敗した場合は以前の設定を維持します。

同じ画面に「Windows 起動時にトレイで起動する」があります。初期値はオフです。オンにすると現在のユーザーのスタートアップに実行ファイルを登録し、次回サインイン時から編集画面を出さずに常駐します。実行ファイルは継続して使う場所に置いてから設定してください。二重起動は抑止し、2つ目を起動すると既存のアプリのギャラリーを表示します。撮影中や設定画面を開いている間は、その操作を維持します。

他の撮影アプリと競合して登録できない場合は、左下に「PrtSc：登録できませんでした」と表示します。Windows の「設定 → アクセシビリティ → キーボード」にある Print Screen キーで画面キャプチャを開く設定や、他の撮影アプリの割り当てを確認し、Prtsc を再起動してください。Windows の予約済み Print Screen キーは前面・背面で動作が異なる場合もあります。登録方式の仕様は [Microsoft の RegisterHotKey ドキュメント](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) を参照してください。撮影ボタンはホットキーの登録状態にかかわらず利用できます。

## 保存場所

`%LOCALAPPDATA%\Prtsc\Captures\<ID>\`

- `original.png`：元画像
- `preview.png`：注釈を含む画像
- `capture.json`：撮影日時・タイトル・注釈データ
- `recording.mp4`：動画の場合の本体（動画には `original.png` を作成しません）

録画中の一時ファイルは `Captures\.recordings\<ID>\` に作成します。正常保存時または破棄時に片付けますが、失敗時の MP4 は復旧用に残し、エラー画面に場所を表示します。エンコーダーの完了後にのみライブラリへ登録します。強制終了や Windows のシャットダウンで途中の MP4 が再生可能になる保証はありません。

保存枚数・描画色・線の太さ・矢印スタイル・文字書式・撮影ホットキー・自動起動の設定は `Captures\settings.json` に保存します。自動起動を有効にした場合は、現在のユーザーのレジストリ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に `Prtsc` を登録します。オフにするとその登録を削除します。ドラッグ用 PNG は `Captures\.drag-exports\` に個別のスナップショットとして作成するため、後の編集・ライブラリの自動削除で内容が変わりません。作成から24時間を超えたスナップショットは、次の起動またはドラッグ時に削除します。この一時キャッシュはライブラリの枚数には数えません。

クラウド送信はありません。履歴の削除は対象フォルダを削除します。編集画面の最小化・×・Alt+F4ではトレイに格納し、編集状態と撮影キーを維持します。トレイの右クリックメニューから撮影・ギャラリー・編集画面・終了を選べます。「終了」でアプリを終了し、トレイアイコンと撮影キーの登録を解除します。Windows のサインアウト・シャットダウンも終了処理を妨げません。

通知やギャラリーから編集を開くときは、編集画面を表示・アクティブ化してから元の画面を閉じるか隠します。最小化からの復元、[Windows の前面表示 API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)、レイアウト後のフォーカス処理を共通化しています。編集画面を常に最前面に固定する設定は使用しません。

最小化でトレイに格納する際は、非表示にしてから最小化状態を解除し、通常表示または最大化の状態を保持します。編集を再開するときは、タスクバーに再表示する前に状態を復元し、Windows 側に最小化が残っていれば [SW_RESTORE](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow) で復元します。

`Assets/Prtsc.svg` はアイコンのベクター原稿、`Assets/Prtsc.ico` は16〜256pxの7サイズを含む Windows アイコンです。`tools/Build-Icon.ps1` で再生成できます。

## 検証

```powershell
dotnet build -c Release
$test = Start-Process .\bin\Release\net10.0-windows\Prtsc.exe -ArgumentList '--self-test' -Wait -PassThru
if ($test.ExitCode -ne 0) { throw 'Self-test failed: see self-test-error.txt' }
Get-Content self-test-result.txt
```

自動テストは画面の撮影や実際のクリップボードの変更を行いません。範囲・ウィンドウ選択の座標計算、全注釈ツールの描画、既存注釈の選択・色変更・削除と Undo / Redo、再読み込み後の文字・矢印・ペンの再編集、画像として合成されるコピー出力、ギャラリーのコピーボタン、文字ダイアログのボタン位置、通知のクリック動作、表示時間の保存・入力検証、0秒での非表示と指定秒数のアニメーション（途中の透明度と自動終了）、アプリとトレイのアイコン資源、ファイルロックの解除を検証します。コピー先にはテスト用の受け取り処理を差し込みます。テスト用データは作業フォルダに一時作成して削除し、画面の描画結果を `artifacts/` に残します。

保存枚数については設定保持・再起動・自動削除・選択中画像の削除・無制限・入力検証をテストします。ドラッグ出力については PNG の原寸・注釈・データ形式・変更されないスナップショット・キャッシュの期限切れ削除・ドラッグ開始の閾値をテストします。

ズームが保存画素・画像サイズを変更しないこと、トリムと元画像の画素の一致、文字の折り返し保持、トリムの保存・Undo / Redo・キャンセル・再編集・コピー・DnD、標準ウィンドウでのツールバー高さと既存コントロールのサイズも検証します。

文字書式の保存と再読み込み、太さからの独立、旧形式の文字の互換性、背景・枠線の描画とトリム後の一致、複数選択・複製・重なり順・微調整・一括削除と Undo / Redo、描画設定の保持、ホットキー設定の検証、拡大鏡の端・倍率・ピクセル寸法、二重起動用の通知と終了後の再起動も検証します。テストはスタートアップのレジストリや実際のグローバルホットキーを変更しません。Windows サインイン時の自動起動と、キー変更後の実際の撮影は実機での確認が必要です。

実際のデスクトップ撮影、実ウィンドウの検出・選択、異なる DPI のモニターをまたぐ選択、グローバル撮影キー、OS のクリップボード連携、通知の実モニター上の位置、タスクトレイの操作、エクスプローラーや他アプリへの実際のドラッグ操作は、この実装環境では対話操作を検証していません。利用する Windows 環境で確認してください。

動画の自動テストは設定の初期値・無音時のデバイス非選択・マウスのサイズ遷移・複数モニター座標・動画の保存／再読み込み／DnD／削除と、画像編集画面との切替を検証します。次の追加テストは、合成したアニメーション画像だけを使って**実際に H.264 MP4 を生成**し、合成後の赤い円のサイズ・透明度・追従、一時停止／再開、MP4 の終了処理とデコードを確認します。デスクトップ・マイク・PC の音は取り込みません。

```powershell
$videoTest = Start-Process .\bin\Release\net10.0-windows\Prtsc.exe -ArgumentList '--recording-self-test' -WindowStyle Hidden -Wait -PassThru
if ($videoTest.ExitCode -ne 0) { throw 'Recording test failed: see artifacts/recording-test-error.txt' }
Get-Content artifacts\recording-test\result.txt
```

実デスクトップの録画、PC の音とマイクの取り込み、OS 側での録画パネル除外とグローバルなマウス入力は、利用する Windows 環境で確認してください。
