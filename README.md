# Prtsc

Screenpresso に着想を得た、Windows 用のスクリーンショット・注釈アプリの初期実装です。独自の UI を持ち、画像と編集データをローカルに保存します。

## 起動

Windows と .NET 10 Desktop Runtime が必要です。開発には .NET 10 SDK を使用します。外部 NuGet パッケージはありません。

```powershell
dotnet run --project Prtsc.csproj -c Release
```

ビルド済みの場合は `bin\Release\net10.0-windows\Prtsc.exe` を直接起動できます。

## できること

- 範囲撮影、クリックしたウィンドウの撮影、画面全体の撮影。撮影時はアプリ自身を隠します。
- `PrtSc` によるグローバル撮影。アプリ起動中に利用できます。ドラッグで範囲を指定するか、クリックでウィンドウを選択します。
- 複数モニターを含むデスクトップの撮影。範囲の座標を画像のピクセル座標に変換します。
- 矢印、四角、丸、自由描画、蛍光ペン、複数行の文字、連番マーカー。
- 注釈の色・太さの変更、Undo / Redo。
- 履歴の自動保存・再読み込み・削除。元画像と注釈データを別々に保持します。
- PNG の書き出しと、注釈を含む画像のクリップボードコピー。
- PNG / JPEG / BMP / GIF / TIFF の読み込み、ファイルのドロップ、画像の貼り付け。

GIF / TIFF は先頭フレームの静止画として読み込みます。注釈の変更は追加・Undo / Redo に対応し、配置済み注釈の移動や文字の直接修正はまだありません。

## 操作

1. `PrtSc` または「範囲をキャプチャ」で選択画面を開きます。ドラッグで範囲を指定し、クリックで枠の付いたウィンドウを撮影します。「ウィンドウを選択して撮影」ボタンではクリック専用モードで開始します。`Tab` でモードを切り替え、`Esc` で中止できます。
2. 上のツールバーで注釈を選び、画像の上でドラッグします。文字と番号はクリックして配置します。
3. 「コピー」または「PNG を保存」で編集結果を取り出します。
4. 左の履歴を選ぶと、保存した画像にさらに注釈を追加できます。

| キー | 操作 |
| --- | --- |
| PrtSc | 撮影の選択画面（ドラッグで範囲、クリックでウィンドウ） |
| Tab | 撮影の選択画面で範囲 / ウィンドウ専用モードを切替 |
| Ctrl+O / Ctrl+V | 画像を開く / 画像を貼り付け |
| Ctrl+S / Ctrl+C | PNG 保存 / 画像をコピー |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| A / R / E | 矢印 / 四角 / 丸 |
| P / H / T / N | ペン / 蛍光ペン / 文字 / 番号 |
| Esc | 撮影または描画中の注釈を中止 |

色と太さは次に追加する注釈に適用されます。文字のサイズも太さに連動します。

ウィンドウ撮影は、選択画面を開いた時点で画面に表示されている画像を、対象ウィンドウの枠で切り出します。画面外の部分は除外し、他のウィンドウに隠れている部分は画面に見えている状態で写ります。最小化したウィンドウ、別の仮想デスクトップの非表示ウィンドウ、デスクトップ背景とタスクバーは選択対象にしません。

### PrtSc が反応しない場合

他の撮影アプリと競合して登録できない場合は、左下に「PrtSc：登録できませんでした」と表示します。Windows の「設定 → アクセシビリティ → キーボード」にある Print Screen キーで画面キャプチャを開く設定や、他の撮影アプリの割り当てを確認し、Prtsc を再起動してください。Windows の予約済み Print Screen キーは前面・背面で動作が異なる場合もあります。登録方式の仕様は [Microsoft の RegisterHotKey ドキュメント](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) を参照してください。撮影ボタンはホットキーの登録状態にかかわらず利用できます。

## 保存場所

`%LOCALAPPDATA%\Prtsc\Captures\<ID>\`

- `original.png`：元画像
- `preview.png`：注釈を含む画像
- `capture.json`：撮影日時・タイトル・注釈データ

クラウド送信はありません。履歴の削除は対象フォルダを削除します。アプリを閉じると撮影キーの登録も解除されます。現在は常駐・トレイ機能はありません。

## 検証

```powershell
dotnet build -c Release
$test = Start-Process .\bin\Release\net10.0-windows\Prtsc.exe -ArgumentList '--self-test' -Wait -PassThru
if ($test.ExitCode -ne 0) { throw 'Self-test failed: see self-test-error.txt' }
Get-Content self-test-result.txt
```

自動テストは画面の撮影やクリップボードの変更を行いません。範囲選択の倍率変換・逆方向のドラッグ・境界処理、ウィンドウの重なり順での選択、負座標のモニター配置・画面外ウィンドウの切り出し、PrtSc 表示と撮影ボタン、全注釈ツールのレンダリング、PNG サイズ、編集データの復元、実際のボタン経由の Undo / Redo と保存、ファイルロックの解除を検証します。テスト用データは作業フォルダに一時作成して削除し、UI の描画結果を `artifacts/editor-preview.png` に残します。

実際のデスクトップ撮影、実ウィンドウの検出・選択、異なる DPI のモニターをまたぐ選択、グローバル撮影キー、クリップボード連携は、この実装環境では対話操作を検証していません。利用する Windows 環境で確認してください。

スクロール撮影、動画録画、ぼかし、切り抜き、既存注釈の選択・移動、常駐、インストーラーは今後の追加対象です。
